# India Prison Analytics

Descriptive and Predictive Analytics on Indian Prison Data using Python, Exploratory Data Analysis (EDA), Data Visualization, and Machine Learning.

## Project Overview

This project aims to analyze historical prison statistics in India, identify patterns and trends, and develop predictive models for prison-related outcomes.

## Objectives

- Perform data cleaning and preprocessing.
- Conduct Exploratory Data Analysis (EDA).
- Analyze state-wise prison statistics and demographic distributions.
- Visualize patterns and trends using statistical techniques.
- Build and evaluate machine learning models for predictive analytics.

## Dataset

**Source:** [Prison in India – Kaggle](https://www.kaggle.com/datasets/rajanand/prison-in-india/data)

## Technologies

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook
