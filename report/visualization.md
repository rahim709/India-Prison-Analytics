# Data visualization report

We visualize prison-system conditions, demographic composition and convicted IPC patterns. The notebook begins with population, overcrowding, capacity and legal-status findings before exploring more detailed patterns. Every chart is generated by plotting code in its analysis cell, displayed inline, and saved at 300 dpi for this report.

## Visualization methodology

We retain one version of each overlapping analytical view. Annual convict/undertrial bar panels duplicate the fixed-panel legal-status area chart, so only the area chart is retained. Total-population rankings, occupancy distributions and correlation figures answer different questions and remain.

Rankings use a single year, while annual series use fixed geographic coverage. Religion uses the corrected schema. Crowded religion/education and crime pies are replaced with readable bars. Punishment indicators retain literal source definitions: the life-imprisonment field is not assumed to enumerate all inmates serving life sentences. Crime facets represent reported convicted inmates, not victim counts or crime incidence. Their thematic groups are plotting choices rather than certified legal taxonomies.

Plot choice follows the observation unit and analytical question. The final assignment-specific plot-coverage review remains documented in the implementation plan.

## Reproduction and interpretation

Run `MPLCONFIGDIR=/tmp/prison-mpl python -m src.analytics.visualization` or execute the visualization notebook. Each additional figure exports its plotted values under results/tables/visualization. Counts from different sources and years are not unique-person totals. Percentages use each panel’s own denominator. Crime trend facets use the same eligible jurisdictions throughout; latest-year rankings retain the available 2013 coverage. Correlations do not establish causality. Small pie slices are identified in legends. Stem-and-leaf rounding affects only that display.
